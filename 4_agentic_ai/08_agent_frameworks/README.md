# 8. Other agent frameworks

[← 7. LangGraph](../07_langgraph/README.md) · [↑ Agentic AI contents](../README.md) · [9. Multi-agent systems →](../09_multi_agent/README.md)

Once you know the raw agent loop (1) and LangGraph (7), compare how other frameworks package the same ideas.

**Prerequisites:** the agent loop (1), LangGraph (7).

## What you'll learn

| Framework | Style |
|---|---|
| **Claude Agent SDK** | The agent harness behind Claude Code: tools, files, subagents built in |
| **CrewAI** | Role-based "crews" of agents with tasks |
| **AutoGen** | Agents that talk to each other in conversations |
| **OpenAI Agents SDK** | Lightweight agents with handoffs |
